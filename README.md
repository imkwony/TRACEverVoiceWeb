# TRACE ver1.11web — 음성 입력 · 서버 없이 브라우저만으로 동작

발표자료(PPTX/PDF) + **발표 음성 파일(mp3·wav 등)** 을 올리면, 음성을 **전사하지 않고 그대로 모델에 전달**해 이해도를 평가하는 웹앱입니다. GitHub Pages에 올려 누구나 자기 BAZE API 키로 쓸 수 있습니다 (키는 저장하지 않고 브라우저 → BAZE로만 전송).

- 발표자료 PDF는 **파일 그대로** 모델에 전달합니다(Gemini 계열 모델, BAZE Gemini 네이티브 경로 `inline_data`, 14MB 이하). Gemini가 아니거나 더 크면 모든 쪽을 이미지로 그려(최대 30쪽) 전달합니다. 거부되면 "⛔ PDF 파일 직접 입력을 받지 못했습니다"로 알립니다.
- ※ 브라우저에서 Gemini 네이티브 경로를 호출할 때 BAZE의 CORS 허용 여부는 확인되지 않았습니다. 막히면 알림이 뜨며, 그때는 Gemini가 아닌 모델(쪽 이미지 방식)을 쓰거나 Python판(ver1.11)을 쓰세요.
- 음성은 mp3·wav는 그대로, 그 외 형식은 브라우저에서 16kHz 모노 wav로 변환해 이해도 평가 호출마다 첨부합니다(20MB 이하).
- 모델이 이미지·음성 입력을 거부하면 오류로 알려줍니다. 음성·이미지 입력 형식은 BAZE 문서에 없어 OpenAI 호환 형식(`input_audio`, `image_url`)을 시도합니다.
- 결과는 폴더 저장(File System Access API) 또는 zip 다운로드로 가져갑니다.
